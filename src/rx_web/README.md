# Publishing plots

This project is meant to:

- Pick up the plots generated by the $R_X$ analysis
- Build the `www` directory meant to be used to create a website
according to [these](https://webeos.docs.cern.ch/create_site/) instructions.

# Organizing plots

In order to build the site

- The plots that will apear in each page will have to be in the same directory
- These plots are produced in a directory structure that does not conform to what might be needed

Therefore there are a few workflows that can be used to organize them:

## Collect plots 

If scanning the BDT, the PID, etc. Once the fits have been done, extract the
plots with:

```bash
rxweb collect-plots -n rare
```

where `rare` is the name of the directory inside `$ANADIR/fits/data/`

## Build directory structure 

Here all the components of the fit appear in the same page. To do this run:

```bash
configs=(
  "rk_ee_jpsi.yaml"
  "rk_ee_psi2.yaml"
  "rk_mm_jpsi.yaml"
  "rk_mm_psi2.yaml"
  "rkst_ee_jpsi.yaml"
  "rkst_ee_psi2.yaml"
  "rkst_mm_jpsi.yaml"
  "rkst_mm_psi2.yaml"
)

for cfg in "${configs[@]}"; do
    snakemake -s snakemake/rules/web/web.smk \
              -c 5 \
              --configfile "snakemake/configs/web/$cfg" \
              --config name='reso_dtf-latest' \
              --logger=snkmt \
              --quiet
done
```

which will:

- Run the workflow in `web.smk` with 5 processes
- Use the configuration in `rk_reso_ee.yaml`
- Pick up plots from fits in the `reso_dtf_v2` directory
- Use the `snakemake-logger-plugin-snkmt` plugin to monitor the progress

To visualize the workflow do in a terminal:

```bash
snkmt console
```
## Create site and open it

For this run:

```bash
rxweb make-html -u -n 4
```

to run the rebuilding of the site from zero with 4 cores.
If the site is stale and you use Firefox, refresh with CTRL+Shift+R for the latest
version.
